### k-middle — Лабораторная работа №1. Распознавание образов на основе контролируемого обучения

**Цель:** изучить особенности методов распознавания образов, использующих контролируемое обучение, и научиться классифицировать объекты с помощью алгоритма K-средних.

**Теория:**  
Контролируемое обучение предполагает наличие априорных сведений о принадлежности каждого вектора обучающей выборки к определённому классу. Основой алгоритмов распознавания является понятие расстояния. Алгоритм K-средних:

1. Фиксируются K ядер (центров областей). Области формируются по правилу минимального расстояния: вектор \(X_p\) относится к ядру \(N_i(r)\), если \(\|X_p - N_i(r)\| < \|X_p - N_j(r)\|\) для всех \(i \neq j\).
2. На \((r+1)\)-м этапе новые ядра вычисляются как среднее арифметическое векторов, принадлежащих области: \(N_i(r+1) = \frac{1}{|N_i(r)|}\sum_{X_p \in N_i(r)} X_p\).
3. Если положение хотя бы одного ядра изменилось, области пересчитываются. Процедура повторяется до стабилизации центров.

### Maximin — Лабораторная работа №2. Распознавание образов на основе самообучения

**Цель:** изучить особенности распознавания образов в самообучающихся системах и научиться классифицировать объекты с помощью алгоритма максимина.

**Теория:**  
В обучении «без учителя» не известны ни классы, ни их количество. Алгоритм самостоятельно определяет классы и их признаки. Критерий — максимальная компактность групп. Алгоритм максимина:

1. Произвольно выбирается первый объект и назначается ядром первого класса \(N_1\).
2. Вычисляются расстояния от \(N_1\) до всех объектов. Ядром второго класса \(N_2\) становится объект, наиболее удалённый от \(N_1\).
3. Оставшиеся объекты распределяются по классам по критерию минимального расстояния.
4. В каждом классе находится объект, максимально удалённый от своего ядра: \(\delta_{ki} = \max d(N_k, X_i)\).
5. Выбирается максимальное из этих расстояний \(\delta_{kp}\). Если \(\delta_{kp}\) больше половины среднего арифметического расстояния между всеми ядрами, создаётся новое ядро \(N_3 = X_p\), иначе алгоритм останавливается.

### Lab3 — Лабораторная работа №3. Разделение объектов на два класса при вероятностном подходе

**Цель:** изучить особенности классификации объектов при вероятностном подходе и научиться находить ошибку классификации.

**Теория:**  
Заданы две случайные величины, распределённые по закону Гаусса:

\[
p(x/j) = \frac{1}{\sigma_j \sqrt{2\pi}} \exp\left[-\frac{1}{2}\left(\frac{x-\mu_j}{\sigma_j}\right)^2\right].
\]

Априорные вероятности \(P(C_1)\) и \(P(C_2)\). Решающее правило Байеса:

\[
P(C_k)p(\vec{X}_m / C_k) \ge P(C_j)p(\vec{X}_m / C_j).
\]

Ошибки классификации:  
- вероятность ложной тревоги \(P_{л.т} = \int_{-\infty}^{x} P(C_2)p(\vec{X}_m / C_2)d\vec{X}_m\);  
- вероятность пропуска \(P_{п.о} = \int_{x}^{\infty} P(C_1)p(\vec{X}_m / C_1)d\vec{X}_m\);  
- суммарная ошибка — сумма этих вероятностей.  
Оптимальная граница \(X^*\) находится из равенства \(P(C_1)p(X_m/C_1)=P(C_2)p(X_m/C_2)\).

### Lab5 — Лабораторная работа №5. Распознавание объектов методом потенциалов

**Цель:** изучить особенности классификации объектов методом потенциалов и научиться применять этот метод на практике.

**Теория:**  
Метод потенциалов относится к контролируемому обучению. Разделяющая функция ищется как суммарный потенциал:

\[
K_{i+1}(x) = K_i(x) + \rho_{i+1} K(x, x_{i+1}),
\]

где корректирующий член \(\rho_{i+1}\) равен \(1\), если \(x_{i+1} \in C_1\) и \(K_i(x_{i+1}) \le 0\); равен \(-1\), если \(x_{i+1} \in C_2\) и \(K_i(x_{i+1}) > 0\); равен \(0\) при правильной классификации.  
Частный потенциал строится через полиномы Эрмита. В пособии приведён пример:

\[
K(\bar{x}, \bar{x}_i) = 1 + 4x_1x_1^{(i)} + 4x_2x_2^{(i)} + 16x_1x_2x_1^{(i)}x_2^{(i)}.
\]

Итеративно уточняя разделяющую функцию, получают границу между классами.

### Lab6 — Лабораторная работа №6. Классификация объектов методом иерархического группирования

**Цель:** изучить правила построения иерархических группировок и метод классификации объектов на их основе.

**Теория:**  
Иерархия \(H\) на множестве \(X\) удовлетворяет условиям: \(X \in H\); \(\forall x \in X, x \in H\); \(\forall h,h' \in H\), если \(h \cap h' \neq \emptyset\), то либо \(h \subset h'\), либо \(h' \subset h\).  
Иерархия строится на основе расстояния. По критерию минимума группы \(A\) и \(B\) объединяются, если \(d(A,B)=\min\{d(A,p),d(B,q)\}\). По критерию максимума — если \(d(A,B)=\max\{d(A,p),d(B,q)\}\). Результат представляется в виде дендрограммы (дерева).

### Lab7 — Лабораторная работа №7. Распознавание объектов с помощью синтаксических методов

**Цель:** изучить особенности синтаксических методов распознавания, методы на основе деревьев и графов, а также грамматические разборы сверху вниз и снизу вверх.

**Теория:**  
Грамматика задаётся четвёркой:

\[
G = <V_n, V_t, P, S>,
\]

где \(V_n\) — нетерминальный словарь, \(V_t\) — терминальный словарь, \(P\) — множество правил подстановки, \(S\) — начальная аксиома.  
Разбор снизу вверх используется для установления принадлежности структуры классу объектов, порождаемых грамматикой. Разбор сверху вниз — для построения объектов по правилам грамматики.  
В пособии рассматривается язык PDL (Picture Description Language) и пример распознавания телоцентрических и V-образных хромосом с помощью грамматики.

### Lab8 — Лабораторная работа №8. Метод автоматической генерации текстовой информации

**Цель:** научиться строить автоматические грамматики на основе обучающей выборки.

**Теория:**  
Задача грамматического вывода: по множеству выборочных цепочек \(\{x_i\}\) построить грамматику \(G\), такую что \(\{x_i\} \subseteq L(G)\).  
Алгоритм состоит из трёх этапов:

1. Строится нерекурсивная грамматика, порождающая в точности заданные цепочки. Используется остаточное правило длины 2.
2. Нерекурсивная грамматика преобразуется в рекурсивную путём слияния остаточных и неостаточных правил.
3. Выполняется упрощение грамматики — удаление эквивалентных и избыточных правил.

В пособии приведён пример построения грамматики для множества цепочек `(caaab, bbaab, caab, bbab, cab, bbb, cb)`.

### lab9 — Лабораторная работа №9. Распознавание образов на основе искусственной нейронной сети

**Цель:** научиться классифицировать объекты с помощью искусственной нейронной сети (ИНС).

**Теория:**  
Рассматривается модель многослойного персептрона. Сеть состоит из входного, скрытых и выходного слоёв. Нейроны соединяются по принципу «каждый с каждым». Работа нейрона:

\[
NET_{jl} = \sum w_{ijl} x_{ijl}, \quad OUT_{jl} = F(NET_{jl} - \theta_{jl}).
\]

Для многослойных сетей функция активации должна быть нелинейной. Обучение с учителем: подаётся обучающая пара \((x, d)\), вычисляется выход \(y\), ошибка \(E = |d - y|\), веса корректируются методом обратного распространения ошибки. Процесс повторяется до минимизации ошибки.  
В пособии приведён пример классификации автомобилей на три класса: легковой, пассажирский, грузовой.
